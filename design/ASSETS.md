# Summer Desktop assets

Generated with the built-in ImageGen tool on 2026-09-09. No API-key CLI fallback.
The supplied sketch was attached to the design-board request. Existing site
styling was not used as a visual reference. The original avatar is retained.

- `summer-reference.png`: day/night home, mobile home and reading-page board.
- `public/images/summer/day.webp`: generated summer landscape, WebP optimized.
- `public/images/summer/night.webp`: same landscape edited to summer blue hour.
- `public/images/summer/*-mobile.webp`: 780 × 1560 center crops for phone displays.
- `public/images/summer/og.jpg`: 1200 × 630 sharing-image crop of the new day wallpaper.
- `public/favicon-summer.png`: original cat avatar resized for the browser tab.
- Dock/control glyphs: Phosphor Icons Core 2.1.1 (MIT), imported as build-time SVG.

## Wallpaper prompt

Generate a single ultra high quality photorealistic summer desktop wallpaper landscape, 2560x1600 wide composition. Beautiful fresh green gently rolling meadow foreground, tiny sparse daisies, low wooded hills and a small quiet blue lake far in distance at lower third. Upper 65 percent open luminous pale blue sky with soft white summer clouds. Sunlit deciduous tree leaves frame only extreme upper corners, especially upper left, gentle warm sun from upper right. Center completely spacious and calm for website glass UI overlay. Premium Apple desktop nature photography, natural nuanced greens not neon, airy optimistic sunny summer afternoon, subtle atmospheric distance, crisp photographic texture. No text no interface no icons no people no buildings no watermark. Full bleed image only.

## Night edit prompt

Edit this exact wallpaper to summer blue hour night. Preserve precisely the same landscape, framing, meadow flowers, leaves positions, hills, lake and camera composition. Remove sunlight, set calm blue summer night with deep cobalt navy sky, faint few stars, soft cool moonlit clouds, dim but visible meadow and lake reflections. Beautiful premium natural night photography, no black crushing, no added objects, no UI no text. Same landscape aspect ratio and high resolution.

## Design-board direction

Four-panel implementation reference: desktop daylight home 1440 × 900,
matching summer night, mobile 390 × 844, and article reading page. Follow the
user sketch: top time bar, left avatar, right greeting and music, bottom Dock.
Use photographic green meadow, blue sky, fine glass edges, translucent pearl
surfaces, restrained shadows, system typography and colorful rounded app icons.
Preserve the original black cat in implementation; reference-board illustrative
content is not real site content. Article surfaces prioritize readability.
