# Wynn’s Save Point · 当前产品与设计说明

状态：当前有效。依据用户于 2026-11-26 确认的「Tactile Spatial Studio Workbench（实体工业质感工作台 + 纯净阅读单页）」重设计方向，彻底替代先前的“复古纸张/朱砂红”“临床心电监护（Live Physical Signal）”以及早期桌面草案。后续方向以用户最新要求为准，并同步更新本文件。

## 产品定位

这是 Wynn 的个人网站。访客可以在首页把玩具有真实功能的工业桌面组件——搜索文章与项目、拨动实体主题开关、用 Mini-CD 播放器听几首纯音乐，并直接打开最近写下的文章或正在做的项目。首页以模块化的真实功能组件组织，不将组件硬编码绑定到会随时间变化的具体项目名称。

文章、项目、关于、搜索是独立入口。长文、短想法和学习记录统一归入文章，通过现有分类与标签组织；不再设独立笔记板块，原 `/notes/` 及其子路径返回 404，不提供兼容页面或重定向。文章与项目正文使用纯净的单页阅读排版，保持高可读性与克制的留白。保留 Wynn’s Save Point 站名、原有像素黑猫头像和真实内容。

## 当前视觉与交互方向

- **冷调工业台面 + 零复古纸张 + 钴蓝与薄荷绿指示色**：
  - 严禁暖米黄、羊皮纸、复古纸张质感与朱砂红/工业橙。
  - **浅色工作台**：冷钛灰微点阵台面（`#EFF2F6`）、纯白单页与卡片（`#FFFFFF`）、拉丝银铝（`#ECEFF4`→`#C9D0DA`）、哑光石墨黑硬件（`#171B22`）、钴蓝主交互色（`#2563EB`）与薄荷绿指示 LED（`#00C982`）。
  - **深色工作台**：曜石炭微点阵台面（`#0C0E13`）、暗炭单页与卡片（`#13161D`）、枪灰拉丝铝、冰钴蓝主交互色（`#3B82F6`）与柔和发光薄荷绿 LED（`#10E896`）。
- **字体**：自托管几何无衬线字体 `Plus Jakarta Sans Variable` 与等宽字体 `JetBrains Mono Variable`，搭配现代中文无衬线回退栈。
- **首页模块化实体组件（全部绑定到稳定全站功能）**：
  - **身份区 + 亚克力黑猫立体徽章**：左上角大字号几何无衬线标题 `Wynn` 与保留原像素黑猫头像的透明亚克力切边立体挂件（点击进入关于页，带轻度指针光泽倾角）。
  - **Mini-CD 实体音频播放器**：右上角半透明磨砂聚碳酸酯盘仓 + 彩虹折射光学 CD 盘片 + 拉丝铝机身，接入 `src/data/music.ts` 与 Web Audio `AnalyserNode`；播放时盘片旋转、LED 亮起、五段电平条跳动；点击展开可调节进度、音量与查看 CC0 说明。
  - **机械搜索条（`⌘/Ctrl + K` / `/`）**：铣削深石墨外壳内嵌 `⌘`、`K`、`↵` 键帽，懒加载 Pagefind 实时检索并支持下拉键盘选择，按回车直达 `/search/?q=...`。
  - **`Writing` 文件夹叠卡**：带文件夹标签页头，动态读取最新公开文章，悬停轻抬卡面、点击直达阅读页。
  - **实体 `THEME` 翘板开关**：自带发光薄荷绿 LED 的实体翘板开关，直接切换浅色/深色主题；下方提供「跟随系统」复位按钮，与全站主题状态机及评论主题保持同步。
  - **`Projects` 磨砂亚克力展盒**：动态读取 `src/content/projects/`，按 `order` 排布，增删项目自动适应；每张样本卡带状态 LED（进行中薄荷绿 / 已发布钴蓝）、状态与版本号以及极简几何标识。
  - **底部极简导航条**：单行收纳 `文章`、`项目`、`关于`、`搜索` 四个核心路由及 GitHub、RSS、写作后台与版权年份。
- **内页阅读体验（纯净单页）**：
  - 内页采用统一的单层精简顶栏（像素黑猫标志、`Wynn`、四项导航、右侧嵌入紧凑拉丝铝 Mini-CD 胶囊与小型主题翘板开关/选择器，消除双顶栏堆叠）。
  - 内容居中铺开于悬浮在微点阵工作台之上的纯净阅读单页（`.sheet-card`），文章与项目详情页配备深色硬件感代码块、钴蓝圆点悬浮目录、阅读进度条、相邻导航和 Giscus 评论。
- **减少动画模式**：关闭光盘旋转、3D 微倾与所有过渡动画，保持清晰静态外观与即时状态切换。
- **被替代的设计**：早期的复古日系游戏菜单（`src/archive/`）、“夏日桌面”（`design/summer-reference.png`）、过渡版“纸墨圆角卡片”以及上一版“Live Physical Signal / 临床心电监护”均已被本版替代，不再作为当前设计要求。

## 项目展示

项目区采用摘要列表与独立详情页，当前按 Rootly → Lanwork → NeoCode → Veil 展示，兼顾产品介绍与个人贡献。列表突出一句话介绍、个人角色和代表成果，辅以技术标签和详情入口。已发布项目可在状态后带上版本号。

详情页按「产品介绍 → 我负责的内容 → 最终成果 → 相关链接」组织。职责使用第一人称并说明团队协作边界；成果以真实交付能力为主，数字需要有可核验的条件和来源。截图仅使用可公开的真实界面，私有项目不提供内部仓库或演示链接。

列表与相邻项目导航按 `order` 升序排列，未设置顺序的排在后面，再按日期倒序与 ID 排序。文章仍使用原有排序和阅读交互。

## 功能与实现边界

保留 Astro、现有内容管理、真实内容、既有页面地址、RSS、SEO 和评论映射。`blog` 内容集合与 `/blog/` 地址是文章板块的兼容约定，不应为修改网站定位而重命名。

主题默认跟随系统且实时响应变化，提供浅色、深色、跟随系统三种选择，手动选择持久保存，评论同步主题（浅色 `light` / 深色 `noborder_dark`）。

音乐由 `src/data/music.ts` 配置，支持稳定标识、歌名、作者、音频地址及可选封面。当前正式歌单是六首 CC0 纯音乐，曲目、作者、来源页面与许可记在 [MUSIC.md](../MUSIC.md)。空歌单仍显示“歌单准备中”并禁用播放。访客主动播放后，单个音频实例跨站内导航持续播放，首页 Mini-CD 机身与内页紧凑拉丝铝胶囊共享状态；刷新不自动播放。保留切歌、拖动进度、时长、音量和失败重试，单曲禁用切歌。测试声音仅用于本地验收，不进入正式歌单。

当前不增加天气服务、登录系统或模拟窗口管理。新增元素应服务于真实浏览、搜索、听歌或内容呈现。

## 文档与验证

[README](../README.md) 提供开发和配置说明；[ASSETS](ASSETS.md) 记录素材来源；[QA](QA.md) 是指定历史版本的验收记录；[历史资料](../src/archive/README.md) 和文章正文均不作为设计指令。

视觉修改需检查桌面与手机的明暗主题、首页机械搜索（`Cmd/Ctrl+K` 与实时结果）、物理主题翘板开关、Mini-CD 连续播放与旋转状态、内页阅读单页对比度、长标题和代码、空状态、键盘操作与减少动画模式。音乐或导航修改还需验证连续播放、前进后退、失败重试和音频实例唯一性。
