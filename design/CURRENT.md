# Wynn’s Save Point · 当前产品与设计说明

状态：当前有效。依据用户于 2026-11-25 确认的「顶部悬浮音乐组件 + 水平滑动心率线上下交替分布模块」重设计方向（纸墨脉搏 / Archival Paper & Obsidian Pulse）。后续方向以用户最新要求为准，并同步更新本文件。

## 产品定位

这是 Wynn 的个人网站。访客可以认识 Wynn、探索项目、阅读文章，也可以在首页沿脉搏时间线停留、听音乐。首页以人为中心，用连续心率线和挂接在其上下的节点表达个人气息与作品脉络。

文章、项目、关于、搜索是独立入口。长文、短想法和学习记录统一归入文章，通过现有分类与标签组织；不再设独立笔记板块，原 `/notes/` 及其子路径返回 404，不提供兼容页面或重定向。文章的阅读体验保持专注舒适，文章列表不承担整个网站的首页结构。保留 Wynn’s Save Point 站名、原有黑猫头像和真实内容；“存档点”表达个人记录与回访的意义，不要求游戏化界面。

## 当前视觉方向

- **纸墨与精密刻度美学**：浅色采用温润纸白（`#f6f5f0`）与炭墨文字（`#161614`），深色采用中性暖炭黑（`#111110`）与暖白文字（`#eceae3`），辅以极淡的工程点阵底纹和克制的朱砂红（`#b8422c` / `#e06b52`）强调色。
- **材质与排版**：去除了全屏风景壁纸、重度液态磨砂玻璃和彩色立体 Dock。页面采用轻薄纸面卡片与 `1px` 细分割线，搭配衬线标题、系统无衬线正文和等宽元数据（数字采用等宽对齐 `tabular-nums`）。像素黑猫头像独立保留于品牌标志与首屏身份节点，不把像素风扩展为全站风格。
- **被替代的设计**：早期的复古日系游戏菜单（`src/archive/`）以及上一版“夏日桌面”（`design/summer-reference.png`、昼夜草原壁纸、液态磨砂玻璃和彩色立体 Dock）均已被本版替代，不再作为当前设计要求。

## 页面与交互

- **顶部结构**：最上方为轻薄粘性导航条（站名与黑猫标志、文章/项目/关于/搜索四个入口、主题选择），其下方居中悬浮音乐播放器胶囊。
- **首页心率线（桌面端）**：居中一条 `1.25px` 精度 SVG 心率脉冲线，5 个存档节点沿水平画布上下交替挂接，通过垂直细引线与线上锚点圆点相连：
  - `01 / IDENTITY`（线上方）：黑猫头像、Wynn 姓名、简介与「关于我」入口。
  - `02 / PROJECTS`（线下方）：以紧凑网格呈现真实项目与状态/版本号，点击进入详情或项目总览。
  - `03 / WRITING`（线上方）：展示最近写下的真实文章与日期；无文章时诚实留空，不编造内容。
  - `04 / SIGNAL`（线下方）：关注方向、本地实时日期时间（不请求定位）与全站搜索入口。
  - `05 / ARCHIVE`（线上方）：收尾说明与 GitHub、RSS、写作后台及版权信息。
- **横向探索交互**：桌面端支持鼠标滚轮映射横滑、空白画布拖拽平移、键盘 `←` / `→` 切点以及底部节点进度导航栏。播放音乐时，线上信号光点沿波形平稳流动；开启减少动画模式后关闭光点流动与微动效。
- **手机端（`< 900px`）**：水平心率线自然转为左侧纵向脉搏脊线，5 个节点沿脊线自上而下排开，适配拇指纵向滑动；音乐胶囊保持紧凑并支持展开完整控制。
- **内页阅读体验**：文章、项目详情、列表、关于、搜索与 404 共用同一纸墨视觉体系，顶部保留紧凑悬浮音乐胶囊，详情页保留目录、代码复制、标签、阅读进度、相邻条目导航和评论。

## 项目展示

项目区采用摘要卡片与独立详情页，当前按 Rootly → Lanwork → NeoCode → Veil 展示，兼顾产品介绍与个人贡献。卡片突出一句话介绍、个人角色和代表成果，辅以技术标签和详情入口，弱化日期与阅读时长。已发布项目可在状态后带上版本号。

详情页按「产品介绍 → 我负责的内容 → 最终成果 → 相关链接」组织。职责使用第一人称并说明团队协作边界；成果以真实交付能力为主，数字需要有可核验的条件和来源。截图仅使用可公开的真实界面，私有项目不提供内部仓库或演示链接。

列表与相邻项目导航按 `order` 升序排列，未设置顺序的排在后面，再按日期倒序与 ID 排序。文章仍使用原有排序和阅读交互。

## 功能与实现边界

保留 Astro、现有内容管理、真实内容、既有页面地址、RSS、SEO 和评论映射。`blog` 内容集合与 `/blog/` 地址是文章板块的兼容约定，不应为修改网站定位而重命名。

主题默认跟随系统且实时响应变化，提供浅色、深色、跟随系统三种选择，手动选择持久保存，评论同步主题（浅色 `light` / 深色 `noborder_dark`）。

音乐由 `src/data/music.ts` 配置，支持稳定标识、歌名、作者、音频地址及可选封面。当前正式歌单是六首 CC0 纯音乐，曲目、作者、来源页面与许可记在 [MUSIC.md](../MUSIC.md)。空歌单仍显示“歌单准备中”并禁用播放。访客主动播放后，单个音频实例跨站内导航持续播放，首页完整悬浮胶囊与内页紧凑悬浮胶囊共享状态；刷新不自动播放。保留切歌、拖动进度、时长、音量和失败重试，单曲禁用切歌。测试声音仅用于本地验收，不进入正式歌单。

当前不增加天气服务、登录系统或模拟窗口管理。新增个人化元素应服务于浏览、停留和表达，不能妨碍入口发现与正文阅读。
