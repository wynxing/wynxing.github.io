# Wynn’s Save Point · 当前产品与设计说明

状态：当前有效。依据用户确认的“夏日桌面”全站重设计，以及 2026-09-10 对个人网站定位的明确修正。后续方向以用户最新要求为准，并同步更新本文件。

## 产品定位

这是 Wynn 的个人网站。访客可以认识 Wynn、探索项目、阅读文章，也可以在首页停留、听音乐。首页以人为中心，用桌面组件和清楚的板块入口表达个人气息。

文章、项目、关于、搜索是独立入口。长文、短想法和学习记录统一归入文章，通过现有分类与标签组织；不再设独立笔记板块，原 `/notes/` 及其子路径返回 404，不提供兼容页面或重定向。文章的阅读体验需要完善，但文章列表不承担整个网站的首页结构。保留 Wynn’s Save Point 站名、原有黑猫头像和真实内容；“存档点”表达个人记录与回访的意义，不要求游戏化界面。

## 当前视觉方向

- 使用写实夏日晴空、绿野和自然树影背景，以及同一构图的蓝调夏夜；桌面与手机分别裁切，中心留出干净空间。
- 呈现 macOS 的精致感：背景模糊、通透染色、细微纹理、边缘高光和柔和投影构成液态磨砂玻璃。首页更通透，阅读面板提高不透明度。
- 采用系统字体栈；Dock 图标为统一的彩色立体圆角方形，中文标签常显。原有黑猫头像独立保留，不把其像素风扩展为全站风格。
- 旧版的复古日系游戏菜单、Quest、Inventory、薄荷色主题与悬浮岛布局均已被替代，不作为当前设计要求，也不复用旧版外观。

## 页面与交互

- 首页顶部是轻薄时间栏，包含站名、访客本地日期与分钟级时间、主题设置；不请求定位。
- 中部左侧放黑猫头像与姓名，右侧上方放时段问候及“写代码，也记下沿途。”，右侧下方放音乐组件。下方是四个入口的悬浮 Dock。
- “最近写下”低调链接最新真实文章；无文章时隐藏，不编造内容填充版面。
- 内页保留紧凑导航和返回桌面入口。列表层级清晰；文章保留目录、代码复制、标签、阅读进度、相邻文章和评论。关于、搜索和 404 使用同一视觉体系。
- 手机端为纵向内容流，底部 Dock 适配安全区域，播放器和正文避免被固定控件遮挡。动效短促柔和，触屏提供按压反馈；减少动画模式关闭装饰动画。

## 功能与实现边界

保留 Astro、现有内容管理、真实内容、既有页面地址、RSS、SEO 和评论映射。`blog` 内容集合与 `/blog/` 地址是文章板块的兼容约定，不应为修改网站定位而重命名。

主题默认跟随系统且实时响应变化，提供浅色、深色、跟随系统三种选择，手动选择持久保存，评论同步主题。

音乐由 `src/data/music.ts` 配置，支持稳定标识、歌名、作者、音频地址及可选封面。正式歌单目前为空，显示“歌单准备中”并禁用播放。访客主动播放后，单个音频实例跨站内导航持续播放，首页完整面板与内页可展开迷你面板共享状态；刷新不自动播放。保留切歌、拖动进度、时长、音量和失败重试，单曲禁用切歌。测试声音仅用于本地验收。

当前不增加天气服务、登录系统或模拟窗口管理。新增个人化元素应服务于浏览、停留和表达，不能妨碍入口发现与正文阅读。
