# Wynn’s Save Point · 当前产品与设计说明

状态：当前有效。依据用户于 2026-11-25 确认的「顶部悬浮硬件感音乐组件 + 水平实时物理心率线 + 极简无框雕塑排版」重设计方向（Live Physical Signal & Borderless Gallery）。后续方向以用户最新要求为准，并同步更新本文件。

## 产品定位

这是 Wynn 的个人网站。访客可以认识 Wynn、探索项目、阅读文章，也可以在首页沿实时物理心率线停留、听音乐并直接与信号线交互。首页以人为中心，用连续物理信号线和无框错落节点表达个人气息与作品脉络。

文章、项目、关于、搜索是独立入口。长文、短想法和学习记录统一归入文章，通过现有分类与标签组织；不再设独立笔记板块，原 `/notes/` 及其子路径返回 404，不提供兼容页面或重定向。文章的阅读体验保持专注舒适，文章列表不承担整个网站的首页结构。保留 Wynn’s Save Point 站名、原有黑猫头像和真实内容；“存档点”表达个人记录与回访的意义，不要求游戏化界面。

## 当前视觉与交互方向

- **高对比单色 + 精密信号橙 + 哑光胶片颗粒**：浅色采用纯净画廊粉笔白（`#f5f5f3`）与纯黑字（`#0a0a0a`），深色采用纯黑画廊暗底（`#070707`）与高亮白字（`#f4f4f2`），全站叠一层极克制（`~3%`）的哑光颗粒微质感，并以信号橙（`#e63e00` / `#ff4d00`）作为唯一精密指示色。
- **彻底去框的无框雕塑排版 + 隔线镜像联动**：去除了圆角白卡片、点阵背景和玻璃容器壳；首页在主节点对侧以「隔线镜像区」填充视觉留白——`01` 对侧呈现实时的档案计数与时钟，`02` 对侧随光标悬停实时切换显示项目的角色、技术栈与代表成果，`03` 对侧随悬停同步切换文章分类、阅读时长与导语摘要。像素黑猫头像保留于品牌标志与首屏身份区。
- **实时物理 Canvas 心率线（60fps）**：
  - **慢速视差背景坐标层 + 多重余晖示波带**：背景铺设以 `0.35×` 速度移动的坐标分度线与十字准星；主心率线后方叠加两条微滞后余晖线与垂直频谱细刻纹。
  - **鼠标拨弦物理**：光标扫过或点击心率线附近，一维弹簧阻尼弦会实时弯曲并荡开余波。
  - **惯性阻尼横滑 + 速度心率联动**：桌面端滚轮、拖拽与方向键驱动弹簧惯性横滑；滑动速度越快，底部实时 BPM 读数与波峰张力同步升高，停下后回落至静息心率。
  - **悬停聚焦共振**：鼠标移入任意项目、文章或节点时，对侧镜像区同步刷新并在心率线上激起脉冲共振，其余无关节点柔和退隐。
  - **真实音频驱动**：顶部悬浮音乐模块接入 Web Audio API `AnalyserNode`，播放时实时驱动顶部五段电平条与心率线波形律动。
- **被替代的设计**：早期的复古日系游戏菜单（`src/archive/`）、“夏日桌面”（`design/summer-reference.png`）以及过渡版“纸墨圆角卡片”方案均已被本版替代，不再作为当前设计要求。

## 页面与交互

- **顶部结构**：最上方为极简粘性导航条（黑猫标志、站名、文章/项目/关于/搜索四个入口、主题选择），其下方居中悬浮硬件微面板风格的音乐控制器，跨站内页面切换保持单个音频实例与 Web Audio 分析器连续播放。
- **首页五个无框节点（桌面端）**：沿实时心率线上下交替以 `1px` 细引线挂接：
  - `01 / IDENTITY`（线上方）：超大字号 `Wynn`、像素黑猫与简介、「关于 / ABOUT」入口。
  - `02 / WORKS`（线下方）：去框横排列出真实项目、简介与状态/版本号。
  - `03 / WRITING`（线上方）：展示最近写下的真实文章与日期；无文章时诚实留空。
  - `04 / SIGNAL`（线下方）：关注方向、本地实时日期时间（不请求定位）与全站搜索入口。
  - `05 / OUTPOST`（线上方）：收尾语句与 GitHub、RSS、写作后台及版权信息。
- **底部仪器刻度尺（桌面端）**：提供 `01 WYNN` 至 `05 OUTPOST` 跳转按钮、进度指针与实时 BPM 读数。
- **手机端（`< 900px`）**：心率线转为左侧纵向实时 Canvas 脉冲脊线，5 个无框节点自上而下排开；顶部音频微面板保持紧凑并支持展开完整控制。
- **减少动画模式**：关闭 rAF 物理循环与粒子动画，在 Canvas 上保留清晰的静态示波器基线，惯性滚动切换为即时响应。

## 项目展示

项目区采用摘要列表与独立详情页，当前按 Rootly → Lanwork → NeoCode → Veil 展示，兼顾产品介绍与个人贡献。列表突出一句话介绍、个人角色和代表成果，辅以技术标签和详情入口，弱化日期与阅读时长。已发布项目可在状态后带上版本号。

详情页按「产品介绍 → 我负责的内容 → 最终成果 → 相关链接」组织。职责使用第一人称并说明团队协作边界；成果以真实交付能力为主，数字需要有可核验的条件和来源。截图仅使用可公开的真实界面，私有项目不提供内部仓库或演示链接。

列表与相邻项目导航按 `order` 升序排列，未设置顺序的排在后面，再按日期倒序与 ID 排序。文章仍使用原有排序和阅读交互。

## 功能与实现边界

保留 Astro、现有内容管理、真实内容、既有页面地址、RSS、SEO 和评论映射。`blog` 内容集合与 `/blog/` 地址是文章板块的兼容约定，不应为修改网站定位而重命名。

主题默认跟随系统且实时响应变化，提供浅色、深色、跟随系统三种选择，手动选择持久保存，评论同步主题（浅色 `light` / 深色 `noborder_dark`）。

音乐由 `src/data/music.ts` 配置，支持稳定标识、歌名、作者、音频地址及可选封面。当前正式歌单是六首 CC0 纯音乐，曲目、作者、来源页面与许可记在 [MUSIC.md](../MUSIC.md)。空歌单仍显示“歌单准备中”并禁用播放。访客主动播放后，单个音频实例跨站内导航持续播放，首页完整硬件微面板与内页紧凑悬浮面板共享状态；刷新不自动播放。保留切歌、拖动进度、时长、音量和失败重试，单曲禁用切歌。测试声音仅用于本地验收，不进入正式歌单。

当前不增加天气服务、登录系统或模拟窗口管理。新增个人化元素应服务于浏览、停留和表达，不能妨碍入口发现与正文阅读。
